# Interactive Hello World CLI Program

A simple, interactive Python command-line program that demonstrates basic Python concepts.

## Features

- 👤 **Personalized Greeting**: Asks for your name and greets you personally
- 📋 **Interactive Menu**: Navigate through multiple options
- 💡 **Fun Facts**: Learn interesting facts about Python
- 🔢 **Interactive Counting**: Enter a number and watch it count
- 🔄 **Loop Practice**: See how while loops work in action

## How to Run

### Option 1: Using Python directly
```bash
python hello.py
```

### Option 2: Using Python 3
```bash
python3 hello.py
```

### Option 3: Make it executable (Linux/Mac)
```bash
chmod +x hello.py
./hello.py
```

## Usage

1. Run the program
2. Enter your name when prompted
3. Choose from the menu options:
   - **Option 1**: Get a personalized greeting
   - **Option 2**: Learn a fun fact about Python
   - **Option 3**: Test the counting feature
   - **Option 4**: Exit the program

## Example Interaction

```
==================================================
  Welcome to Interactive Hello World CLI!
==================================================

What's your name? > Alice

✨ Hello, Alice! ✨

What would you like to do?
1. Greet me again
2. Tell me a fun fact
3. Count something
4. Exit

Enter your choice (1-4): > 3

How high should I count? > 5
Counting: 1 2 3 4 5
```

## Learning Concepts

This program demonstrates:
- User input with `input()`
- String manipulation and f-strings
- While loops and control flow
- Conditional statements (if/elif/else)
- Error handling (try/except)
- Functions and the `main()` pattern
- Docstrings and comments

Enjoy! 🚀
